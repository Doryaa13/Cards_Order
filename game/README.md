# תגובת שרשרת

משחק פאזל דו־ממדי בסגנון מכונת רוב גולדברג, עם [Matter.js](https://brm.io/matter-js/) (מצורף ב-`vendor/`, בלי build).

## הפעלה
- פשוט לפתוח את `game/index.html` בדפדפן (לחיצה כפולה), או
- להריץ שרת סטטי מתיקיית השורש: `npx serve .` ולגלוש אל `/game/`.

## קובץ יחיד לשיתוף
`node game/tools/bundle.js out.html` יוצר עמוד אחד עם כל הקוד בפנים (Matter.js נטען מ-CDN).

## בדיקה בלי דפדפן
`node game/test/sim.js` מריץ כל שלב בסימולציה: בלי חלקים מהמאגר השלב חייב להיכשל, וכל פתרון ב-`solutions` חייב להצליח עם מספר הכוכבים שרשום לו.

## מבנה
- `js/level1.js` – הגדרת השלב: חלקים קבועים (`parts`), מאגר החלקים של השחקן (`tray`) ופתרונות ידועים (`solutions`).
- `js/world.js` – בניית עולם Matter.js מהגדרת שלב (משותף למשחק ולבדיקה).
- `js/editor.js` – מצב עריכה: גרירה מהמאגר ללוח ובחזרה, הזזה וסיבוב בעכבר ובמגע, בלי חפיפה לחלקים אחרים.
- `js/main.js` – לולאת המשחק, ציור, ומעבר בין עריכה, הרצה ותוצאה.

## חוקים
- כל החלקים מהמאגר חייבים להיות על הלוח לפני ההפעלה.
- חלק מהמאגר נדלק כשהכדור או חלק אחר בתנועה פוגע בו.
- ניצחון: הכדור בסל ולפחות חצי מהחלקים נדלקו. ★ = חצי, ★★ = שלושה רבעים, ★★★ = כולם.
